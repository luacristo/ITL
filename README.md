# Лабораторная работа №6: Реализация Client на базе посроенного API

## Цель работы
Целью лабораторной работы является создание клиента для взаимодействия с уже построенным API с использованием библиотеки PyQt6 в языке программирования Python. Задача состоит в том, чтобы построить приложение с графическим интерфейсом, которое будет отправлять запросы к API и отображать результаты.

---

## Требования

- Использование Python и библиотеки PyQt6 для создания графического интерфейса.
- Написание клиента для взаимодействия с API.
- Подключение необходимых библиотек для работы с HTTP-запросами (например, requests).
- Обработка различных типов ответов от сервера.
- Обеспечение пользовательского интерфейса с возможностью отправки запросов и получения данных от API.
- код должен соответствовать PEP
- каждая функция или метод должны содержать docstring, typehints

**UI будет содержать:**

- Список всех сотрудников

    а) (список в виде таблицы, и там кнопочка добавить нового пользователя)
  
    б) напротив каждого сотрудника кнопки edit, delete

```python
class ClientApp(QWidget):
    def __init__(self):
        super().__init__()

        # Инициализация интерфейса
        self.setWindowTitle('Client for API')
        self.setGeometry(100, 100, 600, 400)

        layout = QVBoxLayout()

        # Создание вкладок
        self.tabs = QTabWidget()
        self.tabs.addTab(self.create_employee_tab(), "Список сотрудников")
        layout.addWidget(self.tabs)
        self.setLayout(layout)
```
